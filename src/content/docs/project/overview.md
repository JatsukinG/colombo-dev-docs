# Proyecto Biblioteca

Este proyecto consta de dos aplicaciones web para la administración de una biblioteca física.

<CardGrid>
	<Card title="Admin Dashboard" icon="list">
		Panel de administración para bibliotecarios. Permite gestionar libros, préstamos, usuarios y todo lo relacionado con la operación diaria de la biblioteca.
	</Card>
	<Card title="Catálogo de Usuarios" icon="book">
		Aplicación para usuarios finales. Permite explorar el catálogo de libros, consultar disponibilidad y solicitar préstamos.
	</Card>
</CardGrid>
